# T1 数学作业批改助手

## 故事背景

你来到小学帮助老师批改学生的数学作业。老师收集了5个学生的作业，每个学生完成了5道数学题。这些作业已经整理好，存放在文件中。

你需要编写一个**智能批改助手**，让大语言模型能够读取学生作业，判断每道题的答案是否正确，并输出标准的JSON格式结果。这个工具基于 **PyTorch** 和 **Transformers** 库，可以自动批改作业并生成批改报告。

## 任务目标

你需要在 `submission.py` 中完成**两个核心函数**，让智能批改助手具备以下能力：

### 1. 定义批改规则：`build_system_prompt() -> str`

编写一个 system prompt，引导模型理解作业批改任务，读取学生作业文件内容，判断答案是否正确，并输出标准JSON格式。

**要求**：
- 引导模型理解批改任务（输入：学生作业内容 → 输出：标准JSON批改结果）
- **重点**：说明题目的标准答案，让模型能够比对学生答案
- 引导模型从作业文件中正确识别出：
  - 每道题的学生答案
  - 每道题的正确性判断（true/false）
- 要求模型严格按照标准JSON格式输出
- 强调要识别答案的核心内容，忽略无关的文字说明
- 提供示例帮助模型理解任务

**标准JSON格式**：
```json
{
  "student_id": "学生ID",
  "judgements": [true, false, true, true, false]
}
```

**重要说明**：
- `student_id`：学生ID（如 "student_001"）
- `judgements`：布尔值列表，长度为5，表示5道题的正确性
  - `true` 表示答案正确
  - `false` 表示答案错误

**题目和标准答案**：
1. **题目1**：12 + 35 = ?
   - **正确答案**：47

2. **题目2**：100 - 78 = ?
   - **正确答案**：22

3. **题目3**：6的平方 = ?
   - **正确答案**：36

4. **题目4**：199 + 21 * (2+4) = ?
   - **正确答案**：325

5. **题目5**：【21 - 13】 + 27 = ?
   - **正确答案**：35

### 2. 配置生成参数：`build_generation_parameters() -> dict`

配置模型生成时的参数，控制生成行为。

**可配置的参数**：
- `max_new_tokens`: 最大生成 token 数（默认 512）
- `do_sample`: 是否使用采样（默认 False，使用贪心解码）
- `temperature`: 温度参数（仅当 do_sample=True 时有效）
- `top_p`: nucleus sampling 参数（仅当 do_sample=True 时有效）
- `enable_thinking`: 是否开启 Thinking 模式（默认 False）

**注意**：评测程序会自动处理模板拼装、推理和JSON提取，你只需要专注于 prompt 设计和参数配置。

## 实现要求

### 文件结构

```
LMCC-2025-A/
├── data/
│   └── test_data_T1.jsonl    # T1测试数据（5个学生）
└── T1/
    ├── evaluate.py           # 评测主程序（不可修改）
    ├── submission.py         # 考生实现文件（仅此文件可修改）
    └── README.md             # 本文档
```

**注意**：测试数据位于父目录的 `data` 文件夹中，提交时只需提交 T1 文件夹内的文件。

### 修改规则

- ✅ **仅可修改** `submission.py` 中的两个函数：`build_system_prompt()` 和 `build_generation_parameters()`
- ❌ **不得修改** `evaluate.py` 的任何内容
- ❌ **不得在函数中做JSON后处理**（评测程序会自动处理）

### 技术要求

- 专注于 prompt 设计，引导模型正确理解批改任务
- 合理配置生成参数，平衡生成质量和效率
- 重点考察：
  1. **答案识别能力**：从作业文件中正确提取学生答案
  2. **答案标准化能力**：识别答案的核心内容（如 "47（这个太简单了吧）" → "47"）
  3. **答案比对能力**：将学生答案与标准答案比对，判断正确性
  4. **JSON输出控制能力**：通过 prompt 引导模型严格按照标准JSON格式输出
  5. **Prompt 设计能力**：通过示例和说明帮助模型理解任务

### 提示词长度

- **System Prompt 最大长度**：2048 tokens
- 超过此限制将无法通过评测
- 评测程序会在运行时检查并显示 token 数量

### 输出格式

模型必须输出标准的JSON格式：

```json
{
  "student_id": "student_001",
  "judgements": [true, false, true, true, false]
}
```

**严格要求**：
- `student_id` 字段：
  - 必须与输入的学生ID完全一致
  - 格式为 "student_XXX"（XXX为三位数字）
- `judgements` 字段：
  - 必须是布尔值列表
  - 长度必须为5（对应5道题）
  - 每个元素必须是 `true` 或 `false`
- 必须是有效的JSON格式（可被 `json.loads()` 解析）
- **不要用markdown代码块包裹**（不要用\`\`\`json或\`\`\`）
- 直接输出纯JSON字符串，不要添加任何说明文字

**答案判断说明**：

需要识别答案的核心内容，忽略无关文字：

| 学生答案示例 | 核心答案 | 与标准答案47比对 |
|------------|---------|----------------|
| 47 | 47 | ✅ 正确 |
| 47（这个太简单了吧） | 47 | ✅ 正确 |
| 45 | 45 | ❌ 错误 |
| 2 + 4 = 6;21 × 6 = 126,199+ 126 = 325 | 325 | ✅ 正确（题目4） |
| 我觉得是325？刚才同桌说337我不信😤 | 325 | ✅ 正确（题目4） |

**注意**：需要从各种答案格式中提取核心数字，并与标准答案比对。

## 评测说明

### 环境设置

在运行评测程序之前，请确保已激活正确的 conda 环境：

```bash
conda activate mindspore
```

**重要提示**：
- 必须使用 `mindspore` 环境，否则可能缺少必要的依赖包或版本不匹配
- 如果环境未激活，程序可能无法正常运行或出现导入错误

### 运行方式

**注意**：`--mode` 参数为必选参数，必须指定运行模式。

**演示模式（详细输出）**：
```bash
python evaluate.py --mode demo
```
- 展示每个学生作业的完整批改过程
- 显示模型原始输出、处理后文本、提取的判断结果
- 展示每个学生的判定结果和耗时
- 适合调试和理解模型行为

**评分模式（简洁输出）**：
```bash
python evaluate.py --mode grading
```
- 简洁的进度输出（每个学生一行）
- 最终输出详细评分和性能指标
- 用于正式评测

### 数据格式

**测试数据格式**（JSONL格式，每行一个JSON对象）：
```json
{
  "student_id": "student_001",
  "filename": "student_001.txt",
  "content": "题目：12 + 35\n答案：47\n\n题目：100 - 78\n答案：20\n\n题目：6的平方？\n答案：30\n\n题目：199+ 21 * (2+4)\n答案：325\n\n题目：【21 - 13】 + 27\n答案：32",
  "expected_judgements": [true, false, false, true, false]
}
```

**字段说明**：
- `student_id`：学生ID
- `filename`：作业文件名
- `content`：作业文件内容
- `expected_judgements`：期望的判断结果（正确答案）

**测试数据规模**：
- **自测数据**：5 个学生（data/test_data.jsonl）
- **正式评测数据**：5 个学生（不可见，与自测数据难度分布一致）
- 每个学生5道题，共25道题

### 评测流程

**测试内容**：
- 5 个学生的数学作业（每个学生5道题）
- 逐个进行批改判断
- 测试模型的答案识别能力、标准化能力和判断能力

**示例输入**：
```
题目：12 + 35
答案：47

题目：100 - 78
答案：20

题目：6的平方？
答案：30

题目：199+ 21 * (2+4)
答案：325

题目：【21 - 13】 + 27
答案：32
```

**期望输出**：
```json
{
  "student_id": "student_001",
  "judgements": [true, false, false, true, false]
}
```

**说明**：
- 题目1：47 = 47 ✅ 正确
- 题目2：20 ≠ 22 ❌ 错误
- 题目3：30 ≠ 36 ❌ 错误
- 题目4：325 = 325 ✅ 正确
- 题目5：32 ≠ 35 ❌ 错误

**难点说明**：
- 答案格式多样化，需要提取核心数字
- 包含干扰信息（如表情、文字说明等）
- 需要准确识别学生答案并与标准答案比对

**输出内容**（Demo 模式）：
- 学生ID和文件名
- 作业文件内容
- 模型原始输出（完整）
- 模型输出的JSON（格式化显示）
- 期望的JSON
- 判定结果（✅/❌）
- 单个学生耗时

**评分标准**：
- **每道题 2 分，满分 50 分**（5个学生 × 5道题 × 2分）
- 评测方式：模型输出的JSON与期望JSON**完全匹配**才得分
- 判定规则：
  - ✅ 得 2 分：`judgements[i] == expected_judgements[i]`（单题判断正确）
  - ❌ 得 0 分：判断错误或JSON格式错误
- 必须满足：
  1. JSON格式正确（可被Python解析）
  2. 包含两个必需字段：student_id、judgements
  3. judgements包含5个布尔值
  4. 所有判断与期望一致

**时间限制**：
- 单次评测总时间不得超过 **10 分钟**
- 超时将终止评测
