# 考试必读

## 重要提示

1. **请以每个文件夹中的 README.md 为主阅读题目**

2. **试题的 evaluate.py 都是不可修改的，评测时会使用原版文件**

3. **最终评测时的数据与考生可见的数据不同，但难度分布一致**

4. **环境要求**：运行评测程序前，请确保已激活正确的 conda 环境：

   ```bash
   conda activate MindSpore
   ```

## 文件说明

### 根目录文件

- **考试必读.md** - 本文件，包含整体说明和文件结构说明

### T1/ 文件夹

- **README.md** - T1 题目的详细说明文档（**请以此为主阅读题目**）

- **evaluate.py** - 评测主程序（**不可修改**，评测时会使用原版文件）

- **submission.py** - 考生实现文件（**仅此文件可修改**）

### T2/ 文件夹

- **README.md** - T2 题目的详细说明文档（**请以此为主阅读题目**）

- **evaluate.py** - 评测主程序（**不可修改**，评测时会使用原版文件）

- **submission.py** - 考生实现文件（**仅此文件可修改**）

### data/ 文件夹

- **problem_bank.json** - 题目知识库

- **test_data_T1.jsonl** - T1 题目的测试数据

- **test_data_T2.jsonl** - T2 题目的测试数据

- **similarity_test_T2.jsonl** - T2 题目的相似度测试数据

### documentation/

离线缓存的 PyTorch 及 Transformers 包的文档目录，用于离线查阅相关库的文档说明，可以在其目录下使用 `bash unzip.sh` 解压文档。

## 操作指令

### 下载考试文件

```bash
ma-cli obs-copy obs://obs-lmcc-2025/LMCC-Common/ ~/work/
```

### 第一题自测

```bash
cd /home/ma-user/work/LMCC-Common/T1 && python evaluate.py
```

### 第二题自测

```bash
cd /home/ma-user/work/LMCC-Common/T2 && python evaluate.py
```

### 第一题提交

```bash
ma-cli obs-copy ~/work/LMCC-Common/T1 obs://obs-lmcc-2025/考生账号/
```

例如：`ma-cli obs-copy ~/work/LMCC-Common/T1 obs://obs-lmcc-2025/LMCC-01084/`

### 第二题提交

```bash
ma-cli obs-copy ~/work/LMCC-Common/T2 obs://obs-lmcc-2025/考生账号/
```
