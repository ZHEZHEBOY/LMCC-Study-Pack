## 核心结论

- **确认找到的正式真题**：2025 首届成人组第一轮、第二轮。官方公开形式是“试题解析 PDF”，题面、答案 / 评分点均在其中；第二轮另有官方代码包。
- **只属于样题 / 模拟题**：2025 第一轮例卷、2025 第二轮例题及例题解析、2026 年 5 月版大纲内样题、第二轮模拟练习平台。
- **仍未找到**：2025 两轮独立的无答案净题卷；独立的第一轮答案文件；填好全部 TODO 的第二轮官方参考代码文件；2026 正式真题；2026 专属晋级分数线、精确评级公式和最终软件版本表。
- **没有收录第三方题库**：本轮没有找到同时满足“可追溯到官方真题、无营销污染、内容完整”的第三方材料。宁缺毋滥，避免把回忆题或培训题混成真题。

## 最简使用顺序

1. **先做**：2025 第一轮正式真题；第一次计时、不要先看答案。
2. **再看**：同一份官方第一轮解析，逐题标出薄弱知识点。
3. **回大纲**：只补错题对应模块，再做官方例卷 / 样题复测。
4. **晋级第二轮后**：先读 2025 第二轮成人组正式题和评分点，再用官方代码包复现；最后根据 CCF 后续发布的 **2026 最终环境通知**重建环境。
